Panduan Penggunaan

  1. Buat flipbook — klik “Buat Flipbook Baru”, lalu unggah satu file PDF atau beberapa gambar (JPG/PNG/WEBP).
  2. Atur urutan halaman — seret kartu halaman pada editor untuk menentukan urutan final.
  3. Isi detail buku — judul, penulis, deskripsi, cover, warna tema, ukuran, kecepatan animasi, dan mode baca.
  4. Simpan — flipbook tersimpan di penyimpanan lokal browser (IndexedDB), tanpa server.
  5. Baca — buka buku dari Dashboard/Koleksi. Gunakan tombol panah, keyboard (←/→), swipe di HP, atau ketik nomor halaman.
  6. Fitur reader — mode 1/2 halaman, zoom, fullscreen, thumbnail, bookmark, suara flip, dan daftar isi (jika PDF punya outline).
  7. Bagikan — salin link, buka di tab baru, buat QR code, atau ekspor kembali ke PDF / cetak.
💡 Tips: gunakan PDF berukuran sedang agar rendering lebih cepat. Semua proses dilakukan di browser Anda.
